description: Explore or verify a critical payment-request journey with Playwright.
---

Use the e2e-runner agent. Identify the local frontend URL and existing test command first. For exploration, use playwright-cli with a named session and never production credentials. For repeatable coverage, add or update a focused test in the existing test structure and run that test before widening the suite.

Prioritize authentication, request creation, validation, secure document access, payment/treasury and mobile navigation. Report URL, role, steps, console/network evidence and artifact paths for failures.
